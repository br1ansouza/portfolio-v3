# Brian Souza — Portfolio

Portfólio pessoal, refeito do zero. Página única, estética pixel art, animações GSAP + Lenis.

🚧 Em desenvolvimento — sem deploy ainda.

## Stack

- [Svelte 5](https://svelte.dev/) (runes) + TypeScript
- [Rsbuild](https://rsbuild.rs/)
- [Tailwind CSS 4](https://tailwindcss.com/) + [Skeleton 5](https://skeleton.dev/)
- [GSAP](https://gsap.com/) + [Lenis](https://lenis.dev/)

## Rodando localmente

```bash
npm install
npm run dev
```

Disponível em [http://localhost:3000](http://localhost:3000).

## Outros comandos

```bash
npm run build         # build de produção
npm run preview       # preview do build
npm run check         # svelte-check
npm run lint          # eslint
npm run format        # prettier --write
```
